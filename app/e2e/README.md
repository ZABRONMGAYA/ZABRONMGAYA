# End-to-end tests

`npm run e2e` launches the built app (`npm run build` first) with the engine running from source:

| Spec                    | What it drives                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app.spec.ts`           | The editor workflow on a wedding shoot generated by `mcsync.testing.media`: new project, import, search, sync (positions checked against the truth), timeline, inspector, drag and undo, snap, reject and restore, export in both formats, reopen.                                                                                                                                                 |
| `production.spec.ts`    | A 279-file, two-session production generated by `mcsync.testing.production`, with damaged files, duplicates, silent clips and footage from another event: background import with live counts, pause and resume, quit mid-analysis and resume, errors and retry, the windowed browser, search, results, duplicates, removal from the project (the file stays on disk), offline media and relinking. |
| `timeline-perf.spec.ts` | Frame intervals while panning and zooming a 300-clip, 3-hour timeline served by `fake-engine.mjs` (a stand-in speaking the engine protocol). Skipped on Windows.                                                                                                                                                                                                                                   |

Requirements:

- the engine installed in the Python on `PATH` (or `MCSYNC_PYTHON`): `pip install -e ../engine`;
- FFmpeg on `PATH` (with encoders: the test footage is generated);
- on Linux without a display, a virtual one: `xvfb-run -s "-screen 0 1920x1080x24" npm run e2e`.
  Containers running as root also need `MCSYNC_NO_SANDBOX=1`.

`MCSYNC_E2E_APP=<executable>` runs the suites against a packaged or installed app instead of the development build
(the release workflow does this after installing each installer).

Screenshots of each step are written to `test-results/screens/`.
